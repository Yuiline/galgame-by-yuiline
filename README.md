# galgame by yuiline

一个自学前端的大学生做的视觉小说项目。
慢慢来，先把基础打好。

> 当前版本：**v0.2**（详见 [CHANGELOG.md](./CHANGELOG.md)）

---

## 项目简介

这是我个人完全自主的视觉小说（Visual Novel）项目。
初衷是边学边做，用游戏开发的方式练习前端技能。

**当前状态**：标题画面 + 完整剧情对话系统（75 句，含林韦与思博雅的街头偶遇故事）。
点击屏幕任意位置，或按 `空格` / `回车` 即可推进对话。

---

## 技术栈

- HTML5
- CSS3（Flexbox 布局）
- 原生 JavaScript（ES6）
- 暂未引入框架与构建工具（保持简单）

---

## 如何运行

无需安装任何依赖。

1. 克隆或下载本仓库
2. 双击 `index.html` 用浏览器打开
3. 点击"开始游戏"会跳转到 `game.html`（占位页）
