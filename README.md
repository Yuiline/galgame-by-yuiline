# galgame by yuiline

一个自学前端的大学生做的视觉小说（Visual Novel）项目。
边学边做，慢慢来，先把基础打好。

> 当前版本：**v0.3** — 返回按钮与多场景背景（详见 [CHANGELOG.md](./CHANGELOG.md)）

---

## 项目简介

这是我个人完全自主开发的视觉小说项目，初衷是用"做游戏"的方式练习前端技能。

**当前进度**：

- ✅ 标题画面（`index.html`）+ 开始游戏按钮
- ✅ 完整剧情对话系统（75 句，覆盖炒饭摊、街头偶遇、夜里桥上、河水落幕四个场景）
- ✅ 键盘推进：按 `空格` 或 `回车` 即可推进对话
- ✅ 多场景背景图切换：剧情推进到第 32 句自动切换到夜街背景
- ✅ 返回首页按钮：游戏中可一键回到标题画面
- ⬜ 角色立绘、背景音乐、音效（下一版本计划）

**剧情角色**：林韦（主角 / 第一人称）、思博雅、父亲、内心独白

## 如何运行

**无需安装任何依赖，零配置。**

1. 克隆或下载本仓库
2. 双击 `index.html` 用浏览器（推荐 Chrome / Edge）打开
3. 在标题画面点击 "开始游戏" 进入剧情
4. 点击屏幕任意位置，或按 `空格` / `回车` 推进对话
5. 想返回标题？点屏幕右下角的 `back.png` 按钮即可

> ⚠️ **小提示**：如果用浏览器直接打开 `file://` 协议，Chrome 会在控制台提示 "Unsafe attempt to load URL" 安全警告。**这是浏览器的提醒，不是 bug**，不影响游戏运行。

## 操作说明

| 操作 | 功能 |
| --- | --- |
| **鼠标点击屏幕** | 推进到下一句对话 |
| **空格键** | 推进到下一句对话 |
| **回车键** | 推进到下一句对话 |
| **点击 back.png 按钮** | 返回标题画面（不会触发剧情推进） |
| **点击"开始游戏"按钮** | 从标题画面进入游戏 |

## 技术栈

- **HTML5**：语义化标签 + `dialog` 对话框
- **CSS3**：Flexbox 布局、`position: absolute` 定位、`backdrop-filter` 玻璃质感
- **原生 JavaScript（ES6）**：`const` / `let`、箭头函数、模板字符串、事件监听
- **Git / GitHub**：版本管理 + Pull Request 工作流
- 暂未引入框架与构建工具（保持简单，先打好基础）

## 开发约定

### Git 工作流

- 主分支为 `master`，所有开发在特性分支进行
- 分支命名：`feat/<简述>`、`fix/<简述>`、`docs/<简述>`、`refactor/<简述>`
- Commit Message 遵循 Angular 规范：`<type>(<scope>): <subject>`
- 每个版本通过 Pull Request 合入 `master`

### 命名规范

- HTML 元素 `id` 用驼峰：`story-text`、`game-bg`、`back`
- CSS 类名用小写连字符：`start-button`、`character-img`
- JavaScript 变量用驼峰：`currentIndex`、`storyText`

### 文档规范

- `CHANGELOG.md` 记录每个版本的详细变更（按 Keep a Changelog 格式）
- `README.md` 持续更新功能说明与使用方式（本文件）
- 关键代码块加中文注释，解释"为什么"而不只是"是什么"
